# Fitness Planner — политика конфиденциальности

Дата: 21 ноября 2026

Fitness Planner — дневник силовых тренировок для Android и iOS. Ниже описано, какие данные приложение
обрабатывает, где они хранятся и как их удалить.

## Какие данные обрабатываются

- **Аккаунт.** Если вы входите в аккаунт (по email и паролю или через Google), приложение получает ваш email и
  идентификатор пользователя (uid). Без входа («Продолжить как гость») аккаунт не создаётся.
- **Данные тренировок.** Программа-сплит, выполненные тренировки (упражнения, подходы, вес, повторы),
  заметки к упражнениям, свои упражнения, избранное, замеры тела (вес и обхваты), выбранный «Мой зал».
- **Фото прогресса.** Фото к замерам тела хранятся только на вашем устройстве. В облако они не отправляются.
- **Геопозиция.** Запрашивается только на экране «Залы рядом» и только для поиска залов поблизости в момент
  поиска. Приложение не сохраняет вашу геопозицию и не передаёт её никому, кроме запроса к сервису
  OpenStreetMap Overpass (в нём указаны координаты центра поиска). Разрешение можно не давать: тогда карта
  открывается на центре Алматы.
- **Токен push-уведомлений (FCM).** Если вы вошли в аккаунт и разрешили уведомления, токен устройства
  сохраняется в вашей облачной записи, чтобы приложение могло присылать уведомления.
- **Отчёты о сбоях (Crashlytics).** При сбое приложение отправляет технический отчёт: модель устройства,
  версию системы и приложения, трассировку ошибки. Личные данные тренировок в отчёт не входят.

## Где хранятся данные

- На вашем устройстве: все данные тренировок хранятся локально, приложение работает без сети и без аккаунта.
- В облаке: у вошедших в аккаунт данные тренировок (кроме фото и идущей тренировки) дополнительно
  синхронизируются с Firebase / Google Cloud Firestore (мультирегион eur3, Европа). Правила доступа разрешают
  читать и менять данные только их владельцу.

## Третьи стороны

- **Google Firebase** (Authentication, Cloud Firestore, Cloud Messaging, Crashlytics) — вход, синхронизация,
  push-уведомления и отчёты о сбоях. Политика Google: https://policies.google.com/privacy
- **OpenStreetMap** — тайлы карты и поиск залов через Overpass API. Политика конфиденциальности фонда OSM:
  https://osmfoundation.org/wiki/Privacy_Policy
- **wger.de** — открытый каталог упражнений. Запросы к нему не содержат личных данных.

Данные не продаются и не используются для рекламы. Рекламы и встроенных покупок в приложении нет.

## Удаление данных

- Выход из аккаунта («Профиль → Выйти») стирает с устройства данные, которые хранятся в облаке. Сами облачные
  данные остаются и возвращаются при следующем входе.
- Удалить облачные данные (аккаунт и всё, что синхронизировано) можно по письму на адрес из раздела
  «Контакты». Удалить локальные данные можно, удалив приложение.

## Дети

Приложение не предназначено для детей младше 13 лет, мы сознательно не собираем их данные.

## Изменения политики

При изменении политики здесь обновляется дата. Актуальная версия всегда доступна по адресу этой страницы.
