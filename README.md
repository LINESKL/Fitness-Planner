# Fitness Planner

Дневник силовых тренировок на Flutter для Android и iOS.

## Цель

На тренировке не нужно помнить, сколько и с каким весом делал в прошлый раз. Приложение записывает
упражнения, подходы, вес и повторы, перед каждым упражнением показывает прошлый результат и строит
графики прогресса.

## Целевая аудитория

Люди, которые регулярно занимаются в тренажёрном зале и хотят видеть свой прогресс: от новичков,
которым важно не забыть рабочие веса, до опытных атлетов, следящих за объёмом и рекордами.

## Аналоги

| Приложение | Что хорошо | Чего не хватает |
|---|---|---|
| Strong | Быстрая запись подходов, прошлые значения рядом | Графики и часть функций платные |
| Hevy | Удобная статистика, синхронизация | Социальная лента, которая не всем нужна |
| FitNotes | Бесплатное, работает офлайн | Только Android, устаревший интерфейс |

Отличие Fitness Planner: офлайн-первый журнал, бесплатная статистика, привязка тренировок к залу на карте.

## Экраны

1. Вход и регистрация (email, Google)
2. Главная — последняя тренировка, шаги за день, кнопка «Начать тренировку»
3. Активная тренировка — упражнения, подходы, «в прошлый раз», таймер отдыха
4. Выбор упражнения — каталог с поиском
5. История тренировок
6. Детали тренировки
7. Статистика упражнения — графики веса и объёма, рекорды
8. Карта залов
9. Фото прогресса
10. Настройки — тема, единицы, напоминания

## Технологии

Flutter, Dart, Material 3, Riverpod, GoRouter, dio, Hive, SharedPreferences, Firebase (Auth, Firestore,
Cloud Messaging, Crashlytics), Google Maps, geolocator, wger API, OpenStreetMap Overpass API.

## Структура репозитория

- `lib/`, `test/` — приложение
- `dart_tasks/` — задачи недели 1 на Dart: null safety, классы, коллекции, async/await

## Запуск

